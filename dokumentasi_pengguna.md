# Panduan Pengguna ContentOS 🚀

ContentOS adalah platform Creator Workspace mandiri untuk merencanakan, memproduksi, menganalisis konten media sosial, serta berbagi berkas secara offline di jaringan lokal.

---

## 🔒 1. Akses & Login Pertama Kali

* **Alamat Akses:**
  * Di PC Server: `http://localhost:3001`
  * Di Perangkat Lain (Satu Wi-Fi): `http://<IP-PC-SERVER>:3001` (contoh: `http://192.168.1.15:3001`)
* **Kredensial Default:**
  * **Username:** `admin`
  * **Password:** `admin`
  * *(Ubah password segera setelah masuk di menu **Settings**).*

---

## 🧭 2. Panduan Menu Utama

### 📊 Dashboard (Statistik)
* **Fungsi:** Melihat statistik performa konten secara menyeluruh.
* **Fitur Utama:**
  * Grafik pertumbuhan pengikut (*Followers Growth*).
  * Distribusi konten berdasarkan platform (Instagram, TikTok, dll.).
  * Target pencapaian pengikut per saluran media sosial.

### 📝 Content Planner (Ide & Draft)
* **Fungsi:** Wadah menuliskan ide konten mentah sebelum diproduksi.
* **Alur Kerja:** 
  1. Masukkan **Judul**, **Pilar Konten**, **Target Platform**, dan **Jadwal**.
  2. Gunakan kolom **Notes** untuk draf naskah/riset kata kunci.
  3. Hubungkan ke file mentah (Google Drive/Dropbox) lewat kolom **Reference URL**.

### 📋 Content Bank (Bank Aset)
* **Fungsi:** Database perpustakaan semua konten yang sedang diproduksi atau sudah diterbitkan.
* **Fitur Utama:**
  * Tampilan bisa diubah ke **Grid (Kartu)** atau **Tabel (Padat Informasi)**.
  * Fitur pencarian, filter status, pilar konten, dan platform.
  * Input performa statistik (Views, Likes, Comments, Shares, Saves).
  * **Pilih Banyak:** Klik tombol "Pilih Banyak" untuk memperbarui status atau menghapus beberapa konten sekaligus secara instan.

### 🗂️ Kanban Board (Papan Kerja)
* **Fungsi:** Memantau tahapan produksi konten secara visual.
* **Cara Pakai:** Geser (*Drag & Drop*) kartu konten antar-kolom status produksi:
  * **Idea** (Ide Mentah) ➔ **Scripting** (Naskah) ➔ **Editing** (Penyuntingan) ➔ **Production** (Siap Produksi) ➔ **Ready to Post** (Siap Posting) ➔ **Published** (Selesai Posting).

### 📅 Editorial Calendar (Kalender Jadwal)
* **Fungsi:** Kalender interaktif untuk memetakan tanggal tayang konten.
* **Cara Pakai:** Klik tanggal untuk melihat daftar konten hari tersebut atau merencanakan ide konten baru.

## 📱 3. Berbagi File Gratis Tanpa Kuota (Local Share)

Fitur untuk mengirim video/gambar dari HP ke PC (atau sebaliknya) secara offline tanpa memotong kuota internet.

* **Cara Setup Jaringan Lokal:**
  1. Hubungkan HP dan PC ke **jaringan Wi-Fi yang sama**.
  2. Buka browser HP, akses `http://<IP-PC-SERVER>:3001`.
  3. Buka menu **Local Share** di bilah navigasi kiri.
  4. **Penting (Android):** Jika muncul notifikasi *"Wi-Fi tidak ada internet"*, tekan notifikasi lalu pilih **"Tetap Terhubung"**.
  5. Matikan **Data Seluler** di HP Anda untuk memastikan transfer data murni 100% menggunakan Wi-Fi lokal.
  6. Pilih berkas dan mulai mengunggah/mengunduh secara instan dengan kecepatan maksimal LAN.

## 🔍 4. Optimasi SEO Media Sosial (Social SEO)

Maksimalkan visibilitas akun Anda di mesin pencari (Google, pencarian TikTok, dll.) dengan strategi berikut di ContentOS:

1. **Topical Authority (Otoritas Topik):** Buat 3-5 Kategori Pilar Konten yang spesifik di menu **Settings**. Konsistensi memposting konten sesuai pilar ini meningkatkan relevansi akun di mata algoritma pencari.
2. **Optimasi Keyword (Kata Kunci):** Gunakan field **Notes** saat merencanakan konten untuk riset & menulis kata kunci penting. Terapkan kata kunci ini pada judul, takarir (caption), dan 3 detik pertama naskah video Anda.
3. **Pelacakan Tautan (Link Tracking):** Simpan tautan konten yang sudah terbit di kolom **Reference URL** untuk memudahkan tim melakukan cross-linking dan audit sebaran konten.
